Use directly under the header on the schedule tab, above the first row.

```jsx
<CoverageNote
  coverage="1 of 26 scheduled stations have imported schedules. Times are as published, in UTC."
  permission="default"
  action={<Button onClick={ask}>Enable notifications</Button>}
/>
```

The permission copy is fixed per state — do not soften "blocked" or hide it. A short list must read as an import gap, not as a quiet band, which is what the coverage sentence is for.
