Use inside the directory sheet only. Adopting a row saves the receiver locally, closes the sheet and updates the receiver row.

```jsx
<DirectoryRow location="Moscow region, RU" grid="KO85" users={3} usersMax={7} snr={31} onAdopt={adopt} />
```

Cap the list at 50 and state the total. Saving stores the address in this browser only; the audio connection still goes straight to that node under that node's own rules, and the app never relays anyone else's receiver.
